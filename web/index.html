KIVIL / KISA REHBER
Başlamak için gerekenler.
Her komut ayrı satırda. Bloklar { } ile, koşullar ( ) ile yazılır.
Yazdırma & değerler
isim = "Ada"
puan = 10 + 20 * 3
yaz("Merhaba", isim, puan)
Koşullar & mantık
eger (puan >= 50 ve dogru) {
    yaz("Geçtin")
} degilse {
    yaz("Tekrar dene")
}
Döngüler
tekrarla 3 { yaz("Merhaba") }
iken sayac < 5 {
    sayac = sayac + 1
}
Fonksiyonlar
islev topla(a, b) {
    dondur a + b
}
yaz(topla(3, 4))
Listeler
sayilar = [10, 20, 30]
sayilar[0] = 5
sayilar.ekle(40)
yaz(sayilar.uzunluk())
Girdi & dönüşümler
isim = girdi("Adın: ")
yas = sayi(girdi("Yaşın: "))
yaz(isim, metin(yas + 1))
